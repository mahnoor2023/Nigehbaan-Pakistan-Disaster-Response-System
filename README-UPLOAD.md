# Nigehbaan — Premium UI + Pakistan Coverage

## Recommended GitHub upload
This ZIP contains the **complete project**, including original files and Steps 1 & 2. In GitHub, upload the **contents** of the `Nigehbaan1-main` folder into the repository root (do not upload the enclosing folder). Existing files are replaced, and new files are added. Do not delete existing GitHub files.

- Premium responsive navigation and visual theme
- Pakistan coverage landing page with Karachi–Malir pilot and explicit data labels
